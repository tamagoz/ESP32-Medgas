# ระบบจำลองควบคุมปั๊มสุญญากาศคู่ (Bench Simulator)

> **ข้อจำกัดด้านความปลอดภัย:** ชุดนี้เป็นซอฟต์แวร์จำลองบนโต๊ะทดลองเท่านั้น ไม่ใช่เครื่องควบคุมปั๊ม ไม่ใช่แบบวงจรตู้ และไม่ใช่อุปกรณ์ทางการแพทย์ที่ผ่านการรับรอง ห้ามต่อ GPIO, รีเลย์, คอนแทคเตอร์, เซนเซอร์ หรือโหลดจริงเข้ากับซอฟต์แวร์นี้ ห้ามใช้ควบคุมระบบสุญญากาศหรือระบบจ่ายก๊าซในสถานพยาบาล

## วัตถุประสงค์และขอบเขต

ไฟล์ `DuplexVacuumBenchSimulator/DuplexVacuumBenchSimulator.ino` จำลองตรรกะพื้นฐานของปั๊มสองตัวผ่าน Serial Monitor: cut-in, lag assist, cut-out และสลับปั๊มนำ โดยไม่มีการอ่านหรือเขียนขา GPIO และไม่มีการเชื่อมต่อเครือข่าย จอ เซนเซอร์ หรืออุปกรณ์กำลัง ค่าแรงดันและสถานะปั๊มทั้งหมดเป็นข้อมูลจำลองที่ป้อนผ่าน Serial เท่านั้น

## สิ่งที่ตรวจพบใน repository และแหล่งอ้างอิง

- Repository นี้เดิมเป็นเว็บแดชบอร์ด React/Vite สำหรับระบบ Medgas; ไม่มีเฟิร์มแวร์ปั๊ม คู่มือ หรือแบบวงจรตู้เดิม
- เว็บเดิมกล่าวถึงบอร์ด NOOB-MINI-C3 / ESP32-C3 และรีเลย์ Y1–Y6 จึงเป็นคนละโครงการ/คนละแผนผังขากับตัวควบคุมปั๊มในเอกสารแนบ ไม่ได้นำ pinout ของเว็บมาใช้
- ไฟล์อ้างอิง `Pump_Rev1.cpp` และ README ระบุ ESP32-WROOM-32 DevKit V1; ผู้ใช้ยืนยันเลือกบอร์ดรุ่นนี้สำหรับงานจำลอง ส่วนเอกสารนี้ไม่ได้ยืนยันบอร์ดที่ติดตั้งในตู้จริง
- เอกสารอ้างอิงกล่าวถึงทรานสมิตเตอร์สุญญากาศ 0 ถึง −30 inHg, Modbus RTU 9600 8N1, Slave ID 1, register `0x0000` และสเกล signed integer ÷100 รวมถึงอินพุตอนาล็อกสำรอง แต่ไม่มี datasheet/register map จากผู้ผลิตมายืนยัน ค่าเหล่านี้จึงไม่ถูกนำไปอ่านในโปรแกรมจำลอง
- ไม่มีป้ายชื่อมอเตอร์หรือรุ่น/พิกัดอุปกรณ์กำลังจริงในข้อมูลที่ให้มา จึงไม่มีการระบุขนาดเบรกเกอร์ คอนแทคเตอร์ โอเวอร์โหลด สายไฟ หรือแบบเดินสายที่ใช้สร้างตู้ได้

### ความขัดแย้ง/ข้อจำกัดในแหล่งอ้างอิง

| ประเด็น | ข้อมูลในเอกสาร | การจัดการใน bench simulator |
|---|---|---|
| Cut-in / Cut-out | README และโค้ดอ้างอิงให้ −15 / −20 inHg | ใช้เป็นค่าเริ่มต้นเพื่อสาธิตซอฟต์แวร์เท่านั้น ไม่ใช่ค่าที่อนุมัติสำหรับระบบจริง |
| Lag assist | README/โค้ดให้ 180 วินาที แต่คู่มือระบุช่วงปรับ 1–5 นาที | ใช้ 180 วินาทีเพื่อทดสอบ โดยระบุว่าเป็นค่าอ้างอิงที่ยังไม่ผ่านอนุมัติ |
| Modbus fallback | README ระบุให้เปลี่ยนไป Analog หลังล้มเหลว 5 ครั้ง แต่โค้ดลอง Analog ตั้งแต่ครั้งแรก | ไม่มีการอ่าน Modbus หรือ Analog ในโปรแกรมจำลอง |
| รีเลย์ Active-LOW | โค้ดกำหนด `RELAY_OFF = HIGH` แต่ checklist ใน README อ้างว่า GPIO `LOW` คือ OFF | ไม่ใช้ GPIO หรือรีเลย์ จึงไม่กำหนดระดับ ON/OFF ทางไฟฟ้า |
| Manual / Emergency Stop | คู่มือบรรยาย selector และการตรวจ EMG; โค้ดตัวอย่างไม่มีอินพุตอ่าน selector หรือ EMG | ไม่มีโหมดควบคุมโหลดจริง ไม่มี EMG/selector input |
| Interlock | ผังบางส่วนใส่ NC interlock ระหว่าง KM1/KM2 แต่ lag assist ต้องเดินปั๊มคู่ | ไม่มีวงจรหรือการต่อคอนแทคเตอร์ในเอกสารจำลอง |
| Fault/restart | แหล่งข้อมูลไม่สอดคล้องกันในรายละเอียดการ latch/reset และการกลับมาทำงาน | จำลอง fault ได้เพื่อทดสอบการแสดงสถานะเท่านั้น ไม่ถือเป็นข้อกำหนดระบบจริง |

| เอาต์พุตปั๊ม/รีเลย์ | ไม่มี; แสดงสถานะจำลองบน Serial เท่านั้น |
| Wi-Fi, Modbus, Analog, RTC, TFT | ไม่ได้ใช้งาน |
| ค่าเริ่มต้นจำลอง | Cut-in −15.0 inHg, cut-out −20.0 inHg, lag assist 180 วินาที |
| ช่วงค่าที่โปรแกรมจำลองยอมรับ | −30.0 ถึง 0.0 inHg (มาจากช่วงที่ระบุในไฟล์อ้างอิง; ไม่ใช่การยืนยันความถูกต้องของเซนเซอร์) |

### Pinout

**ไม่มี pinout ที่ใช้ได้สำหรับการต่อฮาร์ดแวร์ในงานนี้.** Sketch ไม่มีการตั้งค่า GPIO. ตารางต่อไปนี้เป็นเพียง mapping ที่พบในไฟล์อ้างอิง ห้ามนำไปต่อวงจรโดยไม่ตรวจบอร์ดจริง, datasheet และแบบที่วิศวกรผู้รับผิดชอบอนุมัติ:

| GPIO ที่อ้างใน `Pump_Rev1.cpp` | หน้าที่ที่ไฟล์อ้างอิงกล่าวถึง | สถานะใน simulator |
|---:|---|---|
| 32, 33 | คำสั่งรีเลย์ Pump 1/2 | ไม่ใช้ |
| 34 | อินพุต Analog สำรอง | ไม่ใช้ |
| 36, 39 | อินพุต optocoupler overload | ไม่ใช้ |
| 16, 17, 25 | UART/ทิศทาง RS-485 | ไม่ใช้ |
| 21, 22 | I²C RTC | ไม่ใช้ |
| 18, 23, 5, 2, 4, 15 | SPI/TFT/backlight | ไม่ใช้ |

## หลักการทำงานจำลอง

สุญญากาศแสดงเป็นค่าติดลบ: ค่ายิ่งติดลบมากหมายถึงสุญญากาศลึกขึ้น. เมื่อค่า **มากกว่า** cut-in (เช่น −14.8 > −15.0 inHg) โปรแกรมจำลองเริ่มปั๊มนำ. หากครบ lag delay แล้วยังไม่ถึง cut-out จะเริ่มปั๊มตาม. เมื่อค่า **น้อยกว่าหรือเท่ากับ** cut-out (เช่น −20.0 inHg) จะหยุดสถานะปั๊มจำลองและสลับคิวปั๊มนำสำหรับรอบถัดไป.

`advance <วินาที>` ใช้เลื่อนนาฬิกาจำลองเพื่อทดสอบ timer โดยไม่ต้องรอเวลาจริง. ค่าความดันไม่เปลี่ยนเอง: ผู้ทดสอบต้องใช้ `set <ค่า-inHg>` ป้อนค่าจำลองแต่ละจุด. ดังนั้นการจำลองไม่ได้จำลองพลวัต/อัตราการดูดของปั๊มจริง.

## แผนภาพวงจรสำหรับ bench simulator

```text
คอมพิวเตอร์ / Serial Monitor
          │ USB serial (ข้อมูลข้อความเท่านั้น)
          ▼
ESP32-WROOM-32 DevKit V1
          │
          └── โปรแกรมจำลองในหน่วยความจำ
                ├── ค่า vacuum จำลองจากคำสั่ง set
                ├── เวลา/lag จำลองจากคำสั่ง advance
                └── สถานะ Pump 1/2 แสดงทาง Serial

ไม่มีสายจาก GPIO ไปยังเซนเซอร์ รีเลย์ คอนแทคเตอร์ มอเตอร์ หรือวงจรไฟฟ้าเมน
```

นี่ไม่ใช่ schematic ของตู้ปั๊มจริง. ไม่แสดงการต่อ 220/380/400 VAC, วงจรกำลัง, วงจรควบคุมคอยล์ หรือ wiring schedule เพราะรุ่นอุปกรณ์และแบบที่อนุมัติยังไม่มี และคำอธิบายทั่วไปจากไฟล์แนบไม่เพียงพอสำหรับสร้างวงจรอย่างปลอดภัย.

## การติดตั้งและทดสอบ

### Arduino IDE

1. ติดตั้ง Arduino IDE และแพ็กเกจบอร์ด Espressif ESP32 จากแหล่งทางการ
2. เปิด `DuplexVacuumBenchSimulator/DuplexVacuumBenchSimulator.ino`
3. เลือกบอร์ด ESP32 Dev Module ที่ตรงกับ ESP32-WROOM-32 DevKit V1 จริง และเลือกพอร์ต USB ที่ถูกต้อง
4. Compile และอัปโหลดด้วยสาย USB เท่านั้น; **ห้ามต่อวงจรภายนอกกับ GPIO**
5. เปิด Serial Monitor ที่ 115200 baud และเลือก line ending แบบ Newline

### Arduino CLI (ตัวอย่าง compile)

จาก root ของ repository:

```powershell
arduino-cli compile --fqbn esp32:esp32:esp32 .\DuplexVacuumBenchSimulator
```

FQBN อาจต่างกันตามแพ็กเกจบอร์ดที่ติดตั้ง. คำสั่งนี้เป็นการคอมไพล์ bench simulator เท่านั้น ไม่ใช่คำแนะนำอัปโหลดไปยังตู้ที่ต่อโหลด.

### คำสั่ง Serial

| คำสั่ง | ตัวอย่าง | ผลที่คาดหวัง |
|---|---|---|
| `help` | `help` | แสดงคำสั่งที่รองรับ |
| `status` | `status` | แสดงเวลา/แรงดัน/สถานะจำลอง/คิว |
| `set <ค่า>` | `set -14.8` | ตั้งแรงดันจำลอง; ค่าอยู่นอก −30 ถึง 0 จะถูกปฏิเสธ |
| `advance <วินาที>` | `advance 180` | เดินเวลาจำลองและประเมิน control logic ทุกวินาที |
| `trip <1 หรือ 2>` | `trip 1` | จำลอง overload ของปั๊มที่เลือก; ปั๊มจำลองนั้น unavailable |
| `cleartrip <1 หรือ 2>` | `cleartrip 1` | คืนสถานะปั๊มจำลองหลังตรวจแล้ว |
| `sensor <ok หรือ fail>` | `sensor fail` | จำลองข้อมูลเซนเซอร์ถูกต้อง/ขัดข้อง |
| `reset` | `reset` | ล้าง fault lock ใน simulator เมื่อเงื่อนไขจำลองพร้อม |
| `mode <auto หรือ off>` | `mode off` | เปลี่ยนโหมดจำลอง (ไม่มีสวิตช์ฮาร์ดแวร์) |

### Test sequence

1. เริ่มต้นตรวจ `status`; ยืนยันว่าแสดงว่าเป็น simulator และปั๊มจำลองหยุด
2. ป้อน `set -14.8`; ตรวจว่าเข้าสู่ LEAD_RUN และเริ่มปั๊มนำจำลอง
3. ป้อน `advance 179`; ยืนยันว่ายังไม่มี lag assist
4. ป้อน `advance 1`; ยืนยันว่าเข้าสู่ LAG_ASSIST เมื่อครบ 180 วินาที
5. ป้อน `set -20.0`; ยืนยันว่าหยุดปั๊มจำลองและสลับ lead สำหรับรอบต่อไป
6. ป้อน `set -14.8`, ตามด้วย `trip 2`; ยืนยันการโอน lead ใน simulator ไปยัง Pump 1
7. ป้อน `trip 1`; ยืนยัน `FAULT_LOCK` เมื่อปั๊มจำลองทั้งคู่ unavailable จากนั้น `cleartrip 1` และ `reset`
8. ทดสอบ `sensor fail` และ `sensor ok`; ยืนยันว่า simulator แสดง/ล้างสถานะ sensor fault ตามข้อมูลจำลองเท่านั้น
9. ทดสอบค่าที่ไม่ถูกต้อง เช่น `set 5` และ `advance -1`; คำสั่งต้องถูกปฏิเสธ

## ข้อควรระวัง

- สถานะ `RUN`, `TRIP`, `AUTO` หรือ `FAULT` ในหน้าจอ Serial เป็นเพียงค่าจำลอง ไม่ยืนยันสถานะของอุปกรณ์จริง
- การป้อนแรงดันด้วยคำสั่ง Serial ไม่ใช่การสอบเทียบ/ทดสอบทรานสมิตเตอร์
- ห้ามเชื่อมต่อ ESP32 กับรีเลย์หรือโหลดจริง แม้ใช้บอร์ดและ GPIO ตามเอกสารแนบ
- ห้ามใช้ mapping, ค่าแรงดัน, ค่า timing, BOM, หรือรายละเอียดอุปกรณ์ในเอกสารอ้างอิงเป็นคำสั่งซื้อ แบบต่อสร้าง หรือ commissioning
- ห้ามทำงานกับ 220/380/400 VAC โดยอาศัยเอกสารชุดนี้ งานไฟฟ้ากำลังและระบบสุญญากาศต้องออกแบบ/ตรวจสอบโดยผู้มีคุณสมบัติตามข้อกำหนดที่เกี่ยวข้อง
- การหยุดระบบจริง, Emergency Stop, overload, phase protection, sensor redundancy, alarm, restart และการควบคุมด้วยมือ ต้องกำหนดและทดสอบแยกโดยวิศวกรผู้รับผิดชอบ ไม่สามารถสรุปจาก simulator นี้
- ไม่มีหลักฐานการประเมินความเสี่ยง การตรวจรับ การสอบเทียบ การทวนสอบซอฟต์แวร์ หรือการรับรองตามมาตรฐานการแพทย์ใด ๆ
